## The category

Type 2 diabetes mellitus is E11 in ICD-10-CM, in Chapter 4, endocrine, nutritional and metabolic
diseases. The chapter separates diabetes by cause rather than by treatment: diabetes due to an
underlying condition, drug- or chemical-induced diabetes, type 1, type 2, and other specified
diabetes each have their own three-character category. Where the record says only "diabetes
mellitus" with no type stated, the classification defaults to type 2.

That default is worth knowing in both directions. It means an unqualified diagnosis does not stall
the coding, and it means a record that meant type 1 but did not say so is classified as the wrong
disease. Insulin use does not change the category — a person with type 2 diabetes taking insulin is
still coded to E11, with long-term insulin use recorded as a separate status code.

## E11 is a family, not a single code

E11 is never used at three characters. The fourth and subsequent characters name the complication,
which is what makes this one of the larger combination-code families in the classification. The
subcategories cover kidney involvement, retinal involvement subdivided by severity and by whether
macular edema is present, neuropathy including the polyneuropathy and autonomic forms, circulatory
involvement of the limbs with or without gangrene, skin, oral and joint complications, and the
metabolic states of hyperglycemia and hypoglycemia, the latter distinguished by whether coma
occurred. Diabetes documented without complications has its own code ending in the digit 9, which is
the source of the frequently quoted E11.9.

Several of these still require a second code. Diabetic chronic kidney disease is paired with a code
for the stage of kidney disease; a diabetic foot ulcer is paired with a code giving its site and
depth. The combination code names the association, and the additional code carries the detail.

## The "with" convention

The reason this family works the way it does is a general convention rather than a diabetes rule.
Where the alphabetic index links two conditions with the word "with", the classification reads that
as "associated with" or "due to" and presumes the relationship, without requiring the record to
state it explicitly. A record listing type 2 diabetes and chronic kidney disease is therefore coded
as diabetic kidney disease unless the documentation says the two are unrelated.

This presumption is the single most consequential detail in coding diabetes, and it is also the one
most often applied too enthusiastically. It holds only for the pairings the index actually lists,
and a condition merely appearing on the same problem list is not automatically a diabetic
complication.

## Codes that commonly accompany E11

Long-term use of insulin, of injectable non-insulin agents, and of oral glucose-lowering drugs each
have distinct status codes, and body mass index has its own set. Screening for diabetes in someone
without symptoms is an encounter code rather than a diagnosis. Prediabetes and abnormal glucose
findings that fall short of a diabetes diagnosis are not coded to E11 at all; they belong with the
other abnormal glucose findings in the same chapter.
